# Scorpion MK74 v74.0.0

MK74 is the autonomy, personality and proactive-intelligence release following MK50.

## Highlights

- Adds a central local-first Autonomy Policy.
- Local read-only observation and local computation can proceed without unnecessary prompts.
- Direct cloud/API use, persistent mutations and update application require fresh explicit approval.
- Adds a Proactive Engine that can recommend relevant next steps from context, memory gaps, repeated local failures and pending improvements.
- Proactive suggestions never auto-execute.
- Refines Scorpion's personality continuity while preserving serious-mode overrides.
- Extends the HUD with LOCAL-FIRST autonomy state and the current suggested next move.
- Adds a NEXT MOVE view for transparent proactive recommendations.
- Retains MK47 context/memory/model-routing intelligence.
- Retains MK50 Build Mode, Ollama recovery, wake recovery and Windows autostart.

## Update path

A correctly installed MK50 recognizes `v74.0.0` as newer and can offer this signed release through the existing updater. Installation remains explicitly confirmed and protected by Ed25519 signature verification, SHA-256 checks, allowlisting and post-install self-check.

## Privacy

MK74 does not add automatic cloud upload of memory, screenshots, microphone audio or Build Mode frames. The private release-signing key is not included in GitHub or release assets.
