# Scorpion MK22 v22.0.0

MK22 is the local-first Scorpion upgrade focused on better voice interaction, safer desktop control and stronger local intelligence.

## Highlights

- Calm female High German voice with slightly reduced speaking speed.
- Wakeword flow with a 20-second command window and barge-in while Scorpion is speaking.
- Structured local long-term memory.
- Google Drive memory sync remains opt-in per memory item or project block.
- Local active-app context and optional local screen analysis without automatic screenshot retention or cloud upload.
- Explicit first-use trust for desktop apps.
- Mutating and critical actions keep confirmation gates.
- Hardware-aware local routing for deterministic commands, chat, reasoning and vision.
- Bounded model-performance learning stores statistics only, never prompts or screenshots.
- Direct OpenAI use stays behind one-time approval and LOCAL mode keeps it locked.
- Signed update verification with Ed25519, package/file SHA-256 checks, self-check and rollback.

## Privacy defaults

MK22 does not automatically upload raw screen captures, microphone audio, secrets, tokens, cookies, private keys or complete chat logs. Model downloads, cloud AI use, Drive sync and update installation remain confirmation-gated.
