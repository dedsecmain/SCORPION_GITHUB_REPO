# Scorpion MK90 (development branch)

**Status: in development, not released.** The `main` branch, MK74
release manifest and automatic updater must not be changed by MK90.

## Components

- `mk90_browser.py`: optional, read-only Playwright Chromium preview,
  with a new ephemeral browser context each time; no clicking, form filling,
  uploads, downloads, password handling, persistent profiles or purchases.
  HTTPS only, with local and private IP literals blocked; JavaScript is disabled,
  cross-origin redirects and resources are blocked, and the user must
  confirm the destination host before each visit.
- `mk90_site_resolver.py`: recognize natural German website names, use an offline\n  official-domain list for familiar websites and optional DuckDuckGo HTML\n  lookup for other names. External lookups require approval *before*\n  sending the requested name to the search provider. Search results are\n  **unverified suggestions**; the destination domain requires another\n  explicit approval before Playwright can open it. No account credentials\n  are supplied to the search provider.\n- `mk90_scan_worker.py`: LlamaFirewall **REGEX** scanner, plus a
  Guardrails AI custom validator that flags credential assignments. These
  are basic checks, not comprehensive prompt-injection defense; full
  model-backed scanning (such as PromptGuard) requires a separate setup
  and evaluation before deployment.
- `mk90_security.py`: subprocess bridge that invokes both scanner
  environments independently and blocks on errors or denials.
- Existing `ActionPolicy`, confirmation callback and local
  metadata-only audit log remain in charge of sensitive actions.

## Windows / Python 3.12 setup

The test installs already exist in separate folders for the user's
Windows profile. Do **not** install all tools in one global Python 3.14
environment, where dependencies previously conflicted.

1. Create/use a Python 3.12 venv for Scorpion itself. Install existing
   `app/requirements.txt` there.
2. Install `playwright` into that Scorpion runtime:
   `python -m pip install playwright>=1.63,<2` (use quotation marks
   around this constraint in PowerShell) then
   `python -m playwright install chromium`.
3. Existing security venvs should be located at
   `%USERPROFILE%\ScorpionMK90\firewall` and
   `%USERPROFILE%\ScorpionMK90\guardrails`. Verify with
   `<venv>\Scripts\python.exe -m pip check` for each.
4. Start the app from this `scorpion-mk90` branch, **not** main.
5. Once its dependencies and approval dialog are verified, explicitly set
   `SCORPION_MK90_BROWSER_ENABLED=1`.
6. After confirming the separate scanners run successfully on real
   harmless and adversarial text, set
   `SCORPION_MK90_SCANNERS_ENABLED=1`. Any scanner error blocks the
   page preview. No scanner model download is initiated here.

Use text commands such as `lies die webseite von Netflix`,\n`öffne die Webseite von Spotify` or `lies webseite https://example.com`.\nFor unfamiliar names, Scorpion asks before sending the name to DuckDuckGo;\nsearch HTML may change or be blocked, in which case enter a URL manually.\nScorpion will ask permission and\ndisplay a limited text-only preview. Web text is *untrusted content*,
not instructions to the assistant. **No passwords, login forms or
payments are automated in this phase.**

## One-command development launcher

After the branch is pulled and Python 3.12 + Playwright are set up, use
`app\\run_mk90_dev.bat`. It fast-forwards the MK90 development branch,
isolates the memory and app trust data, forces LOCAL mode, disables
the test-version wake listener and Drive sync, and enables the guarded
browser with both already-installed scanners. Close the app before running
a new test. It does **not** merge or publish any release.

Natural-language examples: `Lies die Webseite von Netflix`, `öffne Netflix`,
`lies die Webseite vom Zoo Zürich`. Unknown names send the requested name
to DuckDuckGo only after explicit approval. Search suggestions may be
outdated or mistaken; check the exact domain in the second confirmation
before opening anything.

## Voice Core decoder fix (October 2026)

Faster-Whisper 1.2.1 calls `av.open(..., metadata_errors="ignore")`,
which PyAV 19 no longer supports. The dependency file now explicitly
requires `av>=11,<19`. For an *existing* Windows development venv,
close Scorpion MK90, then run from PowerShell:

```powershell
$python = "$env:USERPROFILE\\Scorpion-MK90-Dev\\app\\.venv\\Scripts\\python.exe"
& $python -m pip install "av>=11,<19"
if ($LASTEXITCODE -ne 0) { throw "PyAV installation failed" }
& $python -m pip check
$env:PYTHONPATH = "$env:USERPROFILE\\Scorpion-MK90-Dev\\app\\src"
& $python -m scorpion.mk90_voice_check
```

The voice check uses a generated WAV, **does not record any speech, use
cloud services or load any Whisper inference model**, and reports
`VOICE CORE DECODE OK (PyAV ...)` on success. Then launch with
`run_mk90_dev.bat` and test `LOCAL VOICE` with a spoken phrase.
The separate wakeword remains off in this development launcher.

Netflix and other streaming sites may limit read-only previews and show
CAPTCHAs. Do not attempt to bypass them; their normal login and
JavaScript workflows are not part of this experimental reader.

## Spoken responses (MK90)

`LOCAL VOICE` listens and transcribes locally, then returns spoken answers
by default. Typed chat is intentionally text-only. The new **TEST VOICE**
button plays a short German greeting without Ollama or microphone recording.

Voice output follows this fallback order:

1. Existing configured Edge neural voice (internet service, **not** OpenAI;
   may fail if offline or blocked).
2. Windows offline System.Speech / installed German SAPI voice, via an
   isolated PowerShell process. The spoken text is provided on stdin, never
   spliced into executable commands or sent over the network.
3. Existing offline pyttsx3 engine as a last fallback.

Scorpion now logs a local error if all three engines fail. It reports which
engine completed playback in the voice test. Success cannot detect muted
speakers, incorrect output device or inaudible volume; check the Windows
volume mixer and active audio output if no sound is audible.

Update and restart the MK90 DEV launcher:

```powershell
& "$env:USERPROFILE\\Scorpion-MK90-Dev\\app\\run_mk90_dev.bat"
```

In Scorpion, click **TEST VOICE** before testing **LOCAL VOICE**.
Do not merge MK90 into main until the actual PC playback is confirmed.

## Security caveats

URL filtering is a defense-in-depth measure, **not a complete
SSRF/DNS-rebinding defense**. Do not run this browser bridge against
untrusted arbitrary sites in high-privilege enterprise environments
without additional network isolation and hostname/IP validation.
Prompt-injection detection is inherently imperfect. The approval gate
must remain in place even when scanners say ALLOW. Audit metadata
should never include page bodies or credentials.

## Release gate

Before merging into main: branch CI, local Python 3.12 smoke tests,
real scanner worker tests, browser redirects and network hardening
review, regression suite for Ruflo/Qwen/Ollama, and explicit owner approval.
